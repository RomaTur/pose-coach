# Архитектурные решения

## Development build вместо Expo Go

VisionCamera, TFLite, Nitro и Skia требуют нативных модулей внутри приложения.
Expo генерирует iOS-проект из app config; Xcode собирает development build.
Metro обслуживает JS и assets при разработке, но не исполняет события телефона.
Обычные изменения JS не требуют пересборки; изменения нативных модулей требуют.

## Раздельные runtime и владение памятью

Worker камеры подготавливает вход MoveNet и выполняет runSync. GPUFrame жив,
пока модель читает его пиксели; nested finally освобождает GPUFrame, внешний
finally — исходный кадр. Результат копируется в собственный массив точек.
UI runtime хранит позу, рисует Skia-скелет и обновляет кольцо метрик.
В JS передаются угол/видимость для счётчика и редкая диагностическая сводка,
а не изображения или массивы точек.

Worker→UI использует публичный scheduleOnRuntimeWithId и UIRuntimeId, совместимые
с установленным Worklets Legacy Eval. Номер поколения проверяется на обеих
границах; поздний ответ от старой камеры не должен менять новую сессию.
Устаревшие данные очищаются, ошибки не маскируются сохранением старого скелета.

## Чистые автоматы, небольшой UI store

Счётчик принимает угол и время; автомат тренировки добавляет подготовку, паузу,
завершение и активную длительность. Эти модули не импортируют React Native.
Zustand связывает автомат с UI, но не является транспортом кадров.
Clock/id/save внедряются в фабрику store для поведенческих тестов.
Состояние текущего незавершённого подхода не восстанавливается после убийства
процесса; постоянная история содержит только завершённые подходы.

## Два вида постоянного хранения

SQLite хранит историю; Drizzle задаёт типизированный доступ к таблице.
Миграция схемы транзакционна и не понижает неизвестную новую версию.
Повтор сохранения с тем же id и итоговыми полями безопасен; конфликт не затирает
другую запись. Ошибка оставляет завершённый результат для повторной записи.
MMKV хранит небольшую версионированную запись настроек с проверкой типов.
Ошибка чтения не разрешает молча перезаписать неизвестные данные defaults.

## Демонстрация и ограничения

Демо генерирует синтетические точки и использует настоящий код геометрии/счётчика.
Оно помогает проверить UX без камеры, но не измеряет качество модели.
Отдельный mode отделяет демонстрационную историю от реальной.
API, TanStack Query, аккаунты и синхронизация не добавлены без рабочего сценария.
Границы проверенного поведения перечислены в [TESTING.md](TESTING.md).
